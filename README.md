# ♥ 카드 뒤집기 퀴즈

모둠별로 차례대로 엎어 놓은 카드를 뒤집어 문제를 푸는 교실용 웹앱입니다. `index.html`을 크롬이나 엣지로 열면 바로 쓸 수 있습니다.

## 기능
- **모둠·참가자**: 모둠 수 1~12개와 모둠 이름, 모둠별 인원 1~12명과 참가자 이름 입력(모둠 차례 안에서 모둠원이 번갈아 풂, 혼자 하기 가능)
- **문항**: 카드(문항) 수 1~문제 은행 전체, 문제 섞기, 틀린 카드 다시 덮기, 제한 시간(5~300초)
- **카드 게임**: 시작하거나 ‘카드 새로 섞기’를 누르면 카드를 가운데 모아 두 번 섞은 뒤 한 장씩 제자리로 나눠 주는 애니메이션, 모둠 순서대로(모둠 안에서는 참가자가 번갈아) 카드를 뒤집어 문제 풀기 → 정답 보기 → 맞음(+1)/틀림, 점수판·남은 카드·최종 순위, 축하 꽃가루
- **문제 편집**: 문제·정답 수정, 추가, 삭제, 순서 올리기, `문제 | 정답` 형식(또는 엑셀 두 열 복사)으로 한꺼번에 넣기·내보내기. 자동 저장
- **출력**: 문제지(답 쓰는 줄·이름 칸·정답 쪽) 또는 잘라 쓰는 카드(3열), 게임에 쓰는 카드만/전체, A4 인쇄·PDF 저장, 텍스트 복사
- **읽어 주기**: 카드를 열면 문제를 자동으로 읽어 줌(끄기 가능), 🔊 다시 읽기, 정답 읽기, 읽기 속도 0.6~1.4배 (브라우저 음성 합성, 한국어 음성)
- **글자 크기**: 오른쪽 위 `가−` / `가+` (80%~200%)

설정과 문제는 이 브라우저(localStorage)에 저장됩니다.
